# Özelleştirme

1. Demo araç sınıflarını gerçek ve güncel filoyla değiştirin.
2. CSS renklerini markanıza uyarlayın.
3. Mevcut WebP görselleri koruyabilir veya hakları doğrulanmış görsellerle değiştirebilirsiniz.
4. Fiyat, güvence, kilometre ve teslim iddialarını doğrulamadan yayınlamayın.
5. npm test, npm run lint ve npm run build ardından filtreyi ve mobil görünümü kontrol edin.
