# AK Rentacar

Araç kiralama firmaları için işlevsel ve erişilebilir GitHub Pages şablonu.

**Canlı demo:** https://ak-hosting.github.io/ak-rentacar/<br>
**Lisans:** MIT

Kurgusal demo markasıdır; gerçek filo, fiyat, güvence veya rezervasyon sistemi değildir. Mevcut yerel araç görselleri korunmuştur. Yerel filtre ve kişisel verisiz ihtiyaç konfigüratörü içerir. Harici UI kütüphanesi, analiz, çerez veya form gönderimi yoktur.

Yerel önizleme: `python3 -m http.server 8000`

Kontroller: `npm test`, `npm run lint`, `npm run build`

Üretimde fiyat, vergi, kilometre, depozito, sigorta, ehliyet ve teslim koşulları doğrulanmalıdır.
